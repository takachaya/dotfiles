# エグゼクティブサマリー / Slack文案

上長・関係者に「読んだその場で判断・把握してもらう」ための短文を作る。書く前に足りない材料を集め、出力は文案のみ（送信はユーザーが行う）。

## 手順

1. **確認（不明なら先に聞く）**: ①宛先（誰か・関係性） ②目的（判断依頼／共有・報告／依頼） ③判断に必要な材料（コスト・数値・期限）。即断してもらうにはコスト情報が必須。
2. **型（判断依頼の基本3行）**:
   - 1行目: 結論・お願い（何を判断してほしいか）
   - 2行目: 根拠・コスト・影響（即断に必要な数値はここに集める）
   - 3行目: 選択肢と推奨（Yes/No か A/B で返せる形）＋回答期限
   - 詳細・経緯は本文に入れず、末尾に資料リンクで逃がす。共有・報告型は「何が起きたか→影響→次に自分がやること」の3行に読み替える。
3. **スタイル**:
   - `*` による強調は使わない。絵文字・感嘆符なし。
   - 装飾語・美化語・煽り語尾なし（de-ai-writing ハーネスでセルフチェック）。
   - 敬体は簡潔に。クッション言葉で文を伸ばさない。
4. **事実確認**: 数値・固有名詞は出典を確認してから書く。確認できないものは（※要確認）を付けるか、文案から外して口頭確認を促す。

## 規範

- **送信はしない**。Slack への投稿・メール送信はユーザーが明示的に指示した場合のみ（組織ルール）。
- 顧客の固有名は成果物に出さない（マスキング方針がある組織文脈ではそれに従う）。
- 1メッセージ1論点。複数の判断を求めるときは分割を提案する。
